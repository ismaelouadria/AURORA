# References

Track sources that materially influence AURORA: OPM Flow documentation, EGG documentation, Volve documentation, reservoir-engineering sources, reduced-order modeling, reinforcement learning, constrained optimization/safety, and software-engineering references.

Important assumptions should point to exact sources rather than only informal summaries or search results.


## Source policy

Prefer the most direct authoritative source for the claim:

1. official software/data documentation for source-specific semantics;
2. primary peer-reviewed literature for specific methods/models;
3. peer-reviewed technical literature for domain relationships;
4. established reference works for stable fundamentals;
5. bounded qualified expert review where documentary evidence is insufficient.

AURORA experiments are evidence about AURORA under their documented
experimental conditions. They are not substitutes for general
reservoir-engineering authority.

Repository documentation should distinguish source-backed facts, project
assumptions, experimental findings, and unresolved questions.
